# MiniTabTarget

Swaps your tab key to target nearest **player **in pvp contexts, then back to target nearest **enemy **in pve contexts.

This is useful if you do both pvp and pve content where you would normally have to manually change your bindings.

It will automatically detect your target enemy key bindings, but you can manually override these if you wish by:

/run MiniTabTargetDB.TargetKey = "SOMEKEY"

/run MiniTabTargetDB.TargetPreviousKey = "SHIFT-SOMEKEY"
